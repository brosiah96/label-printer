Label Printer support

Print a label from Google Slides using the iPad's normal Print menu. Label Printer is configured for the shop's Epson ColorWorks CW-C6000Pu.

What you need

  • The Label Printer app installed on your iPad.
  • Your iPad on the printer Wi-Fi network, with the configured printer reachable on the same local network.
  • 108 × 152.4 mm labels loaded in the Epson.

This release supports one selected page and one copy per print request at 300 dpi. It supports only the configured printer and label size. Printing does not require a cloud print server or a computer to remain on.

Set up the iPad once

  1. Connect the iPad to the printer Wi-Fi network and turn on the Epson.
  2. Open Label Printer and tap Check printer connection.
  3. Allow Local Network access when iPadOS asks. If access was denied earlier, use Open app settings to enable it.
  4. Wait for the connection result. A successful check means the printer is reachable; check the Epson's own screen for paper, ink or other errors.

Keep the app installed. You do not need to open it before each print. The connection check does not print a label.

Print a label from Google Slides

  1. Open the label in Google Slides. Use a slide sized for the loaded 108 × 152.4 mm labels.
  2. Open the presentation menu, choose Share & export, then Print.
  3. Choose the printer entry marked Label Printer. iPadOS may show a local address as its main name, with Label Printer underneath.
  4. Select 108 × 152.4 mm, one page and one copy. Check the preview, then tap the final Print button.
  5. Check the physical label before printing another.

No separate PDF export or upload is needed. For several labels, send one label at a time. The receiving printer must remain reachable while a job is being sent.

If the printer is missing or unavailable

  • Confirm the iPad is on the printer Wi-Fi network, the printer and its network bridge are on, and the printer's Ethernet cable is connected.
  • Open Label Printer and run the connection check. Confirm Local Network access is enabled for the app.
  • Close the print-options screen and open it again, then select the entry marked Label Printer.
  • If the problem continues, contact support. Routine troubleshooting does not require resetting the printer, network bridge or router.

If a job stops or a label may have printed

  1. Open the iPad's Print Center from the app switcher and cancel the waiting or failed attempt.
  2. Check the Epson and the labels that came out. Resolve paper, ink or other printer errors, and remove any partial label.
  3. If the app reports that the label is held, open Label Printer and tap Review interrupted prints.
  4. Select the local Label Printer, choose the interrupted job, and read the confirmation. Clear the hold only after you have inspected the printer.
  5. Return to Google Slides and print again only if you still need the label.

Clearing a hold does not print or retry anything. The app cannot independently confirm that a usable physical label emerged, and it does not automatically resend an interrupted transfer.

Size, quality and other limits

If content is clipped or shifted, confirm the slide size, selected paper size and loaded labels match. Keep artwork inside the intended label area and inspect the preview. Contact support if alignment remains wrong.

The incoming print document must be no larger than 10 MiB. If a complex page is rejected, simplify the slide and try one page again. Other printers, batch requests and other media sizes are outside this release's supported workflow.

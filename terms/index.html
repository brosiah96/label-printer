Printing guidance

This release supports the configured Epson ColorWorks CW-C6000Pu on the local network, using 108 x 152.4 mm media, one selected page and one copy per request. It requires compatible iPad software, Local Network permission, a reachable configured printer, and suitable supplies.

Check the selected printer, page, label size, and physical result before using the output. A completed network transfer does not independently confirm a correct physical label. After an interrupted job, inspect the printer and cancel any pending system job before clearing a hold or printing again. Clearing a hold does not print a replacement.

The app does not verify label content such as ingredients, allergens, prices, barcodes, or legal notices. Keep source documents separately and check the output for its intended use.

Privacy

Print processing takes place on the iPad, with output sent to the configured printer over the local network. No developer-operated cloud print service or account is required. The Privacy Policy explains local records and voluntary support communications. Use a trusted local network; the printer connection uses unencrypted local transport.
